# 📊 股票策略看板

磊哥专用股票策略看板，整合左侧扫描 × 涨停倍量阴策略。

## 功能

- 📡 **当前信号**：三个策略当日扫描结果（左侧20日、左侧10日、涨停倍量阴）
- 📅 **月度统计**：本月所有历史信号，支持按月筛选
- 🔄 **自动刷新**：每60秒自动刷新数据

## 策略

### 左侧策略 V4d (20日)
- 圆弧底13-28天
- R² > 0.9
- 圆度 a > 0.03
- 单日跌幅 ≤ 7%
- MA5穿MA20金叉

### 左侧策略 10日 (预警)
- 圆弧底 < 13天
- 其他条件同上

### 涨停倍量阴
- T日涨停
- D日倍量阴（量比2-8x）
- 缩量洗盘3-5天
- 评分 ≥ 30分

## 自动化

交易日每30分钟自动扫描（9:45-15:00），结果自动推送到飞书。

## 使用

1. 打开 `index.html`
2. 点击顶部Tab切换"当前信号"和"月度统计"
3. 月度统计支持选择月份筛选

## 数据更新

- 扫描脚本：`auto_scan.py`
- 数据源：Tushare Pro API
- 更新频率：交易日每30分钟
